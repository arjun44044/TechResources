# ----LinkedIn Post-1

🔹 React Core Concepts

* What is React and why it is used?
* Difference between functional and class components
* What are props and state?
* What are React hooks? (useState, useEffect)
* What is Virtual DOM? How does React update UI?

⸻

🔹 Practical React Questions

* How do you fetch data from API in React?
* What happens if API fails? How will you handle error?
* How do you show loading state in UI?
* What is conditional rendering?
* Why do we use key in lists?

⸻

🔹 Coding / Machine Round

* Build a simple counter using state
* Filter a list of items based on input search
* Create a small API fetch and render UI

⸻

⚡ What I learned from this interview

👉 They don’t care about memorized answers
👉 They check how clearly you think while coding
👉 JS fundamentals are more important than React syntax
👉 Real-world handling (loading, error, empty states) matters a lot

⸻

💡 Key takeaway

If you’re preparing for frontend interviews:

* Master JavaScript deeply (closures, async, event loop)
* Be strong in React basics (state, props, hooks)
* Practice API integration + UI edge cases
* Focus on clean reasoning, not just theory
